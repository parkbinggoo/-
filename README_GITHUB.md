# 백약산 — GitHub Pages 자동 멀티플레이

## 배포

1. **`index.html` 하나를 GitHub 저장소 최상위에 업로드**합니다.
2. GitHub 저장소 **Settings → Pages → Deploy from a branch → main / (root) → Save**를 선택합니다.
3. 발급되는 `https://사용자이름.github.io/저장소이름/` 주소를 친구에게 공유합니다.
4. 모든 방문자는 별도 서버 설정 없이 `산에 오르다`를 누르면 같은 공개 산에 접속합니다.

## 구현

- 참조 코드의 공개 MQTT 브로커 방식(`mqtt.js` / `wss://broker.emqx.io:8084/mqtt`)을 백약산에 적용했습니다.
- 닉네임·캐릭터 위치·방향과 화면의 접속 인원은 서로 전송됩니다.
- **한국 표준시 UTC+9의 실제 시간**으로 게임의 낮과 밤이 결정됩니다.
- **가상 날씨**는 한국시간 기준 30분 구간별 고정 결정 함수로 동일하게 표시됩니다(실제 기상 관측 자료 아님).
- **4명은 공개 브로커 기반의 분산 소프트 제한**입니다. 입장 시각과 ID 순으로 상위 4명이 남도록 조정하지만 네트워크 지연에 따라 일시적으로 5명 이상 입장이 가능하거나 표시 인원이 다를 수 있습니다. 4명 정원을 서버 수준에서 엄격히 강제하려면 별도의 권한 있는 서버가 필요합니다.
- 공개 브로커 장애, 접근 차단, WebSocket 제한이 있으면 멀티플레이도 중단될 수 있습니다. 메시지는 공개 채널로 전송하므로 민감한 정보를 넣지 마세요.

## 테스트

서로 다른 두 기기에서 배포한 **동일한 GitHub Pages 주소**를 열고, 두 캐릭터가 화면에 나타나는지 확인합니다. 코드 문법 검사는 통과했지만 실기기 연결은 배포 환경에서 확인해야 합니다.
